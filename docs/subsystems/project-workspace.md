# 本机项目

「新建项目」只接受用户选择的空目录，「打开项目」只读该目录的 `project.json`。同一窗口一次打开一个项目；关闭时丢弃未保存的改动。选图、试妆和排序继续在内存中完成，只有点击「保存项目」才持久化。

[项目存储](../../internal/project/store.go)的 v1 格式用一个快照保存照片副本、三层参数与推荐偏好。照片原始字节以 Base64 编码在项目文件中，随同妆容一次替换，避免文件与草稿失配；不保存原路径、关键点或预览。项目文件没有加密，应保存在用户控制的本机目录。Go 通过受限目录句柄读取和写入，先写同目录临时文件，再核对当前内容与上次读取是否相同；外部修改后拒绝覆盖。

[桌面工作台](../../frontend/src/photo-preview.ts)重开项目时重新验证照片。若保存时已分析过，则使用本机模型重建试妆预览；模型暂不可用时仍保留原图和已存设置，重新分析后可恢复。保存需要当前照片，清除预览不会直接改变磁盘内容。

运行 `make verify`。桌面测试在临时目录内检查非空目录保护、显式落盘、重开后的图层与像素，以及外部修改冲突。

「导出预览」可独立于项目使用。它输出当前工作画布（尚未分析时输出缩放后的原图，长边最多 1024 像素）。[导出模块](../../internal/project/export.go)重新编码 PNG，不复制原图元数据；由原生对话框选择文件，只有目标不存在时才能写入。桌面测试用含 EXIF 的照片验证像素一致、元数据移除和拒绝覆盖。

「移除项目照片」可在有已保存照片的项目中使用，即使当前预览已经清除。它重新保存只含已存偏好的项目快照，清除照片副本、妆容草稿和当前预览；不删除目录、导入原件、已导出的 PNG 或同目录其他文件。移除和保存使用同一版本核对，项目文件有外部变化时不会写入。

通过[真人测试](lipstick-preview.md)的本机样张运行时，可加 `MAKEUPMIRROR_REAL_PROJECT=1`，在隔离临时目录验证真人保存、PNG 导出、重开与移除。

2026-11-12 本机真人验收通过：重开后 819 × 1024 试妆画布逐像素一致，导出 PNG 为 1,334,626 字节，移除后项目快照不再含照片或草稿。页面未观察到外部 HTTP 请求；真人样张和模型未进入仓库。

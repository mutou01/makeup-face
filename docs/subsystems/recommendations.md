# 本地妆容推荐

[预设规则](../../frontend/src/recommendations.ts)维护三套原创搭配，每套有稳定编号、名称、场景、妆感、色板、三层建议强度和说明。[桌面列表](../../frontend/src/recommendation-panel.ts)不依赖照片或模型即可浏览。

排序只使用用户选的场景与妆感：场景匹配计两分、妆感匹配计一分，平分按预设原顺序排列。始终展示三套，未选条件时使用通用顺序；理由只说明实际匹配和色板设计，不推断肤色、脸型或个人特征。换选项只改列表。此流程不使用网络、供应商或持久化存储。

[桌面验收](../../tests/desktop.test.mjs)通过 `make verify` 检查默认顺序、场景优先、妆感排序、回到默认、色板和理由。

分析面部成功后，点击预设的「应用」按钮将颜色、强度和启用状态写入[当前工作台](../../frontend/src/photo-preview.ts)。未定位的图层跳过并给出提示；用户仍可分别编辑。换图或清除预览后重新禁用应用按钮，不会在新照片上自动应用旧预设。桌面测试覆盖完整和部分图层、像素变化、手动调整、切换排序以及清除后的状态。

2026-11-12 用[同一张真人样张](lipstick-preview.md)复跑「日常豆沙」：唇部、双颊和双眼五处分别变化 867、392、332、33、36 个像素，人工标定范围外为 0，页面未观察到外部 HTTP 请求。这验证了预设应用的行为，推荐的审美适用性仍需盲评。

# 照片质量门禁

单人照片经本机模型检测后，先检查[取景与姿态，再检查曝光与细节](../../frontend/src/face-quality.ts)，通过才生成妆容。未通过会保留原图，显示具体重拍建议，不能应用妆容预设。重开已分析项目也走同一门禁，不会自动修改项目文件。

在工作分辨率上，脸部关键点框距边缘至少为短边的 2%（最少 2 像素），宽高至少各 96 像素且各占相应边长的 12%。[MediaPipe 的头部转换矩阵](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker#task-output)提供姿态：侧转超过 25° 或俯仰超过 20° 时拒绝；无法读取取景或姿态也会给出提示。这些是首版门槛，未用多样化样本校准，不能用于判断遮挡。

曝光和清晰度只采样脸部中央，将区域缩放到 96 × 96 像素，在椭圆内计算亮度与局部细节。有效采样中，至少 75% 亮度低于 35 或高于 242 时分别提示过暗、过亮；拉普拉斯响应均方小于 8 时提示明显模糊。透明区域过多时给出无法判断的提示。该规则针对明显问题，未校准肤色、光照、噪声和不同拍摄设备下的错误率。

[桌面测试](../../tests/desktop.test.mjs)通过 `make verify` 覆盖太小、贴边、侧转、俯仰、姿态缺失、过暗、过亮、模糊和正常图，并核对拒绝后已存项目未变。夹具只替换模型输出，曝光和清晰度使用实际画布像素。

2026-11-12，已有 [NASA 真人样张](lipstick-preview.md)通过门禁；真实模型下试妆、导出和重开项目均通过，重开后画布逐像素一致。负例结果来自受控夹具，不能据此推断真实照片的误拒率。

# 本机诊断

「刷新诊断」查看本次会话最近 32 条已完成操作。记录包括本机人脸定位、项目创建、打开、保存、关闭、移除照片和本机妆容预览导出。定位成功表示本机网格已通过照片质量和项目保存所需的结构校验；耗时为粗粒度档位，项目和导出可能包含文件对话框等待。

[会话缓冲区](../../internal/diagnostics/session.go)只接受固定操作、结果和原因，记录取整到分钟的时间及耗时档位。不会写入照片、关键点、请求、错误原文、路径或凭据。记录只存在进程内存，无自动保存或上传。

点击「导出诊断 JSON」才会弹出本机保存对话框。导出使用同一份会话记录，包含格式版本和事件数组；取消不写文件，同名文件不覆盖。[桌面验收](../../tests/desktop.test.mjs)读取实际输出，核对固定字段和时间粒度，并检查路径、地址与密钥标记未被写入。

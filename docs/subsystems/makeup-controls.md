# 妆容精调

口红、腮红和眼影各自支持开关、颜色、强度和范围。范围滑块从 50% 到 100%；100% 使用原安全蒙版，向下调只从原边缘向内收缩，不代表实际覆盖面积的比例。强度单独控制颜色混合程度。改变一层不影响其他层，也不会越过原蒙版或填进原来留空的部位。

[合成器](../../frontend/src/makeup-preview.ts)使用[到安全边界的距离](../../frontend/src/mask-coverage.ts)对蒙版向内收边，边缘保留淡出。范围随项目保存；旧项目缺少该字段时使用 100%。换图或应用预设时恢复该层的完整安全范围。

[桌面验收](../../tests/desktop.test.mjs)逐像素核对每层收缩后的着色是原范围的子集、其他图层不变、恢复 100% 后与原试妆一致；同时覆盖保存重开、旧格式缺省和越界字段拒绝。

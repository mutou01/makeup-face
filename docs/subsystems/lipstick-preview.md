# 合成图口红试妆

在内置的 240 × 240 合成头像上验证单层妆容。头像、唇形和遮罩由[合成图模块](../../frontend/src/sample-lipstick.ts)在本机生成；没有真实照片、模型权重、外部请求或落盘数据。

[页面](../../frontend/src/main.ts)默认关闭口红。启用后可改色和调整 0–100 的强度，关闭或把强度降为 0 恢复原始像素。改变参数总是从同一张原图重算；边缘按唇形遮罩的覆盖率混合，唇区外像素保持原样。最大强度保留一部分原唇纹理。该边界只针对合成图，尚未验证真实嘴唇检测、自然度或性能目标。

验收运行 `npm run verify`。[桌面测试](../../tests/desktop.test.mjs)通过真实控件和画布像素验证启用、改色、调强度、关闭恢复、重复启用和唇区外保真。实现前，旧窗口通过启动测试，新测试因缺少口红试妆预览而失败。

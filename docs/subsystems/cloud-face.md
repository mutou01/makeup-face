# 云端人脸网格接口

正式构建不在用户电脑运行人脸模型。应用仍在本机解码照片、做质量检查、生成三个妆容遮罩并合成画布。云端定位与文字解释是独立设置；生图也应单独接入。

接口为用户配置的完整 HTTPS 地址，路径以 `/face-mesh` 结尾；使用 `Authorization: Bearer <密钥>`。这是一份项目接口约定，需要供应商或网关实现，不能直接填入任意商用人脸或生图端点。密钥存入 Windows 凭据管理器，设置文件只保存引用。保存设置、选图及取消发送均不产生请求。

每次分析都要确认目的地址。请求为 JSON，只有 `topology`（固定为 `mediapipe-478-v1`）、`width`、`height` 和 `image`（Base64 编码的 PNG）。发送当前照片的长边不超过 1024 像素的版本，不含原始元数据。响应为 JSON，返回相同的拓扑和宽高，以及 `faces`：未检出时返回空数组，检出多人时返回两个；每张脸包含按 MediaPipe 顺序排列的 478 个归一化 `points`（每个含 `x` 和 `y`），以及列优先的 4 × 4 `pose`（`rows`、`columns` 和 `data`）。服务端应检测至少两张脸，不得在多人时只返回第一张。应用限制响应体和请求时间，不跟随重定向。

桌面验收使用本机模拟供应商，不上传真人照片；覆盖取消、逐次确认、实际请求字段、元数据清除、错误尺寸和本机试妆。供应商真实定位精度需要另用获授权照片和人工标注评估。
